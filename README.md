# NoteHub

A full-stack note management application built with Next.js, React, and TypeScript.

NoteHub allows users to create and manage personal notes through a responsive web interface with authentication, protected routes, search, filtering, and pagination.

## ✨ Features

* User registration and authentication
* Cookie-based authentication
* Protected routes
* Create, edit, and delete notes
* Search and filtering
* Pagination
* Profile management
* Form validation
* REST API integration
* Responsive user interface

## 🛠️ Tech Stack

### Frontend

* Next.js
* React
* TypeScript
* Zustand
* TanStack Query
* Formik
* Yup

### Backend & API

* Node.js
* REST API
* Axios
* Cookie-based authentication
